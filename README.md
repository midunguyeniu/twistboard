# Twistboard

**Play now:** https://midunguyeniu.github.io/twistboard/

*Board games with a twist, playable right in the browser.*
*Games made by Gary Duc Nguyen*

No account and no game server needed. Online play connects the browsers directly (WebRTC via PeerJS).

## Chess

| Game | Description |
|---|---|
| [Summoning Chess](https://midunguyeniu.github.io/twistboard/games/summoning-chess/) ([rules](games/summoning-chess/README.md)) | Start with only a King. Collect resources with it and summon new pieces next to it.<br>Capture the enemy King to win. |
| [Original Chess](https://midunguyeniu.github.io/twistboard/games/original-chess/) | Classic FIDE chess against the AI, on one device or online.<br>Tournament clocks: Classical, Rapid, Blitz and Bullet. |
| [Chinese Chess](https://midunguyeniu.github.io/twistboard/games/chinese-chess/) | Xiangqi on the river board: checkmate the enemy General.<br>Perpetual check loses. |
| [Racing Kings](https://midunguyeniu.github.io/twistboard/games/racing-kings/) | Both sides start on the bottom rows and race their King to the 8th rank.<br>Giving check is not allowed. |
| [Nine Men's Morris](https://midunguyeniu.github.io/twistboard/games/nine-mens-morris/) | Place 9 stones, then slide them. Three in a row (a mill) removes an enemy stone.<br>Leave your opponent with 2 stones or no moves to win. |

## Gomoku & Tic Tac Toe

| Game | Description |
|---|---|
| [Blind Gomoku](https://midunguyeniu.github.io/twistboard/games/blind-gomoku/) ([rules](games/blind-gomoku/README.md)) | Gomoku where both colors can look identical, so you must remember whose stone is whose.<br>Exactly 5 in a row wins. |
| [Point Gomoku](https://midunguyeniu.github.io/twistboard/games/point-gomoku/) ([rules](games/point-gomoku/README.md)) | Each round three cells go up for a sealed bid, and the higher bid takes each cell.<br>Make 5 in a row to win. |
| [Sliding Tic Tac Toe](https://midunguyeniu.github.io/twistboard/games/sliding-tictactoe/) | Tic tac toe with a limited number of pieces.<br>Once all are placed, you must move one of yours to any empty cell. |
| [Ultimate Tic Tac Toe](https://midunguyeniu.github.io/twistboard/games/ultimate-tictactoe/) | Nine small boards in one. The cell you play sends your opponent to that board.<br>Win three boards in a row to win. |

## Poker

| Game | Description |
|---|---|
| [Equation Hi-Lo](https://midunguyeniu.github.io/twistboard/games/equation-hilo/) | Build an equation from number and operator cards to land closest to 1 (Low) or 20 (High).<br>Bet chips as the cards come out. |
| [Hit, Stay](https://midunguyeniu.github.io/twistboard/games/hit-stay/) | A die sets the limit. Draw cards (HIT) or stop (STAY).<br>Get as close to the limit as you can without going over. |
| [Memory Poker](https://midunguyeniu.github.io/twistboard/games/memory-poker/) | Memorize 16 cards in 30 seconds before they flip face down.<br>Pick 2 of them to make the best poker hand with 3 shared cards. |
| [Poker Dice](https://midunguyeniu.github.io/twistboard/games/poker-dice/) | Roll 5 dice (9 to A) for a poker hand, with two re-rolls.<br>Kept dice are shown face up, and chips are bet in between. |

## Strategy

| Game | Description |
|---|---|
| [Wall Go](https://midunguyeniu.github.io/twistboard/games/wall-go/) | Move a piece up to 2 steps, then build a wall next to it.<br>Fence off territory; the most land wins. |
| [Wall Go II](https://midunguyeniu.github.io/twistboard/games/wall-go-2/) | Wall Go with two piece types: squares move straight, circles can turn a corner.<br>You must move every turn. |
| [Bagh Chal](https://midunguyeniu.github.io/twistboard/games/bagh-chal/) | Nepal's tigers and goats: 4 tigers hunt by jumping over goats.<br>20 goats try to trap every tiger. |

## Puzzles

| Game | Description |
|---|---|
| [Equation Traffic Light](https://midunguyeniu.github.io/twistboard/games/equation-traffic-light/) | Guess a hidden 9-symbol equation.<br>Green, yellow and red lights show what's right, misplaced or missing. |
| [Knight's Tour](https://midunguyeniu.github.io/twistboard/games/knight-tour/) | Move a knight around the board.<br>Visit every square exactly once. |
| [Cube Count](https://midunguyeniu.github.io/twistboard/games/cube-count/) | Spin a 3D pile of cubes.<br>Count how many there are, hidden ones included. |
| [Box Count](https://midunguyeniu.github.io/twistboard/games/box-count/) | A grid of numbers and a target.<br>Count every rectangle whose cells add up to the target. |
| [Slitherlink](https://midunguyeniu.github.io/twistboard/games/slitherlink/) | Draw one closed loop between the dots.<br>Each number tells how many of its sides the loop uses. |
| [Symmetry Puzzle](https://midunguyeniu.github.io/twistboard/games/symmetry-puzzle/) | Turn and fit all the pieces together.<br>Make one mirror-symmetric shape. |
| [Secret Code](https://midunguyeniu.github.io/twistboard/games/secret-code/) | 26 cards, A to Z, each with a number, a color and a shape.<br>Find the 4 cards that match every clue. |

Every game has a vs-AI or solo mode, plus online play with friends.
